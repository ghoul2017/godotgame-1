# UI 功能性设计文档

## 1. 依据、范围和修订规则

### 1.1 设计依据

本文只以以下文档为准：

- `docs/原始设计.txt`
- `docs/整体策划案.md`

UI 功能结论从上述源文档推导；代码、调试入口、临时实现和旧 UI 草稿只作为后续落地参考。若本文与上述源文档冲突，以上述源文档为准。

### 1.2 文档范围

本文描述 UI 功能结构：

- 游戏有哪些正式界面。
- 每个界面有哪些功能区。
- 按钮放在什么位置。
- 按钮触发什么结果。
- 玩家如何在界面之间流转。
- 新游戏和继续游戏如何进入正式流程。

以下内容归入其他文档或流程：

- 程序类、数据类或代码实现。
- 剧情内容、插图和故事事件设计。
- 调试入口和开发工具设计。
- 临时验证按钮、假数据或占位页面管理。

### 1.3 修订规则

后续修改本文时按以下规则处理：

- 与 `原始设计.txt` 或 `整体策划案.md` 不一致的界面对象，用删除或重写完成修正。
- 文档结构错误时，用正确章节替换错误章节。
- 主入口只包含继续游戏、新游戏、设置、退出。
- 轨道站是游戏循环内的永久成长层，由游戏流程、读档或回归结算进入。
- 新游戏后的正式玩法内容使用对应游戏内 UI 承载，不新增独立图片式入口页。

## 2. 总体界面流

正式流程：

```text
主入口
-> 新游戏 / 继续游戏
-> 新游戏流程或存档所在流程
-> 轨道站准备
-> 空投配置
-> 地表远征
-> 火箭装载
-> 回归结算
-> 轨道站
```

核心职责：

- 主入口：存档和系统入口。
- 轨道站：库存、交易、研发、角色、空投准备。
- 空投配置：坐标、空投舱、单位和物资取舍。
- 地表 HUD：RTS 操作、建造、探索、战斗和回归入口。
- 火箭装载：决定带回和遗留。
- 回归结算：写回轨道永久层并复盘轮次结果。

## 4. 全局 UI 规则

### 4.1 屏幕结构

- 轨道站和空投配置使用全屏功能界面。
- 地表远征使用地图全屏 + HUD 覆盖。
- 回归结算使用全屏结算界面。
- 弹窗用于确认、错误和重要选择。
- 正式首屏服务可玩流程入口。

### 4.2 输入优先级

玩家输入优先级：

1. 弹窗和二次确认。
2. 当前打开的 UI 面板。
3. 地表单位选择和指令。
4. 镜头移动。
5. 调试工具。

UI 面板消费自身点击、滚动、确认和取消输入。

### 4.3 通用按钮位置

全屏功能界面：

- 主要确认按钮：右下角。
- 取消 / 返回按钮：确认按钮左侧或左下角。
- 页面切换：左侧页签或顶部页签。
- 筛选 / 排序：列表区顶部。
- 详情关闭：详情区右上角。
- 错误和锁定原因：底部操作区或按钮上方。

地表 HUD：

- 单位命令按钮：右下角命令区。
- 建造入口：右下角命令区。
- 行为模式入口：底部信息面板右侧或命令区上排。
- 地图 / 扫描入口：左下小地图区域或右下命令区。
- 火箭回归相关入口：火箭建筑详情和右下命令区。

### 4.4 状态显示

所有界面需要显示：

- 可执行。
- 资源不足。
- 前置未满足。
- 已完成。
- 锁定。
- 当前选中。
- 已加入当前配置。
- 会产生不可逆影响。

按钮禁用时在附近显示原因。

## 5. 主入口界面

### 5.1 界面目的

主入口负责存档和系统入口。游戏内轨道站功能、地表玩法操作由对应游戏内界面承载。

### 5.2 区域布局

```text
┌──────────────────────────────────────────────┐
│ 顶部：游戏标题 / 当前版本或存档提示          │
│                                              │
│ 左中：主按钮列表              右侧：背景图   │
│                                              │
│ 底部：设置、退出、版权或状态提示             │
└──────────────────────────────────────────────┘
```

功能区域：

- 顶部标题区：显示游戏名和系统状态。
- 主按钮区：继续游戏、新游戏、设置、退出。
- 存档摘要区：显示最近存档所在流程、远征状态或轨道站状态。
- 底部辅助区：版本信息和辅助提示。

### 5.3 按钮

| 按钮 | 位置 | 功能 |
| --- | --- | --- |
| 继续游戏 | 主按钮区第一项 | 读取最近存档，进入存档所在流程节点 |
| 新游戏 | 主按钮区第二项 | 创建新游戏，进入正式新游戏流程 |
| 设置 | 主按钮区第三项或底部左侧 | 打开设置界面 |
| 退出游戏 | 主按钮区末项或底部右侧 | 退出游戏 |

调试入口归入开发配置或调试工具。

## 7. 轨道站总界面

### 7.1 界面目的

轨道站是永久成长层，是每轮远征的起点和终点。轨道站让玩家查看库存、交易、研发、角色和空投准备。

### 7.2 固定布局

```text
┌──────────────────────────────────────────────┐
│ 顶部状态栏：信用点 / 轨道状态 / 提醒 / 远征摘要 │
├──────┬──────────────────────┬────────────────┤
│ 左侧 │ 中央列表区           │ 右侧详情区     │
│ 页签 │ 当前页主要对象       │ 选中对象详情   │
├──────┴──────────────────────┴────────────────┤
│ 底部操作区：筛选 / 排序 / 确认 / 取消 / 原因 │
└──────────────────────────────────────────────┘
```

### 7.3 固定区域

顶部状态栏：

- 左侧：轨道站名称和当前模块标题。
- 中部：信用点、关键资源摘要、当前功能开放状态。
- 右侧：最近一次远征摘要入口、设置 / 暂停入口。

左侧页签区：

- 库存。
- 交易。
- 研发。
- 角色。
- 空投。

中央列表区：

- 显示当前页主要对象。
- 顶部放筛选、搜索、排序。
- 主体按行展示。

右侧详情区：

- 显示选中对象图标、说明、数值、前置、消耗、收益、限制。

底部操作区：

- 左侧：当前筛选条件、锁定原因、失败提示。
- 中部：撤销、清除选择、对比等辅助按钮。
- 右侧：当前页面主要确认按钮。

### 7.4 页签按钮

| 页签 | 位置 | 功能 |
| --- | --- | --- |
| 库存 | 左侧页签第 1 项 | 查看轨道永久库存 |
| 交易 | 左侧页签第 2 项 | 用资源和信用点交换远征选项 |
| 研发 | 左侧页签第 3 项 | 解锁蓝图、协议和空投能力 |
| 角色 | 左侧页签第 4 项 | 查看觉醒者和单位资产 |
| 空投 | 左侧页签第 5 项 | 准备下一轮远征 |

## 8. 轨道站库存页

### 8.1 目的

查看轨道永久资产，包括资源、装备、芯片、工具、单位平台、蓝图和关键物。

### 8.2 区域

- 分类筛选区：列表顶部。
- 库存列表区：中央。
- 详情区：右侧。
- 操作区：底部。

### 8.3 列表内容

每行显示：

- 图标。
- 名称。
- 分类。
- 数量。
- 单个重量。
- 总重量。
- 基础价值。
- 标签摘要。

### 8.4 按钮

| 按钮 | 位置 | 功能 |
| --- | --- | --- |
| 分类筛选 | 列表区顶部 | 切换库存分类 |
| 排序 | 列表区顶部右侧 | 按数量、重量、价值、分类排序 |
| 查看详情 | 点击列表行 | 在右侧打开详情 |
| 标记为空投候选 | 详情区底部 | 把物品加入空投准备参考 |
| 清除筛选 | 底部左侧 | 回到全部库存 |

### 9.2 区域

- 交易分类：中央列表区顶部。
- 交易列表：中央。
- 交易详情：右侧。
- 确认区：底部右侧。

### 9.3 交易分类

- 资源补给。
- 工具装备。
- 武器。
- 芯片。
- 单位平台。
- 蓝图。
- 协议。

### 9.4 按钮

| 按钮 | 位置 | 功能 |
| --- | --- | --- |
| 交易分类 | 列表区顶部 | 切换交易类型 |
| 查看交易 | 点击列表行 | 右侧显示交易详情 |

| 查看库存来源 | 详情区消耗项旁 | 查看对应资源库存情况 |

确认前显示消耗、获得、前置和交易后库存变化。

## 10. 轨道站研发页

### 10.1 目的

消耗资源、纯净数据、蓝图碎片或数据核心，解锁高级建筑、先进武器、无人机协议、深空探测模块和空投舱改进。

### 10.2 区域

- 研发分类：列表顶部。
- 研发项目列表：中央。
- 研发详情：右侧。
- 确认区：底部右侧。

### 10.3 研发分类

- 建筑蓝图。
- 武器蓝图。
- 无人机协议。
- 扫描 / 深空探测。
- 空投舱改进。
- 角色和芯片相关协议。

### 10.4 按钮

| 按钮 | 位置 | 功能 |
| --- | --- | --- |
| 筛选可研发 | 列表区顶部 | 只显示当前可执行项目 |
| 查看全部 | 列表区顶部 | 显示可研发、锁定、已完成项目 |
| 确认研发 | 右下角 | 消耗资源并写入解锁 |
| 查看影响 | 详情区中部 | 展开影响的建筑、装备、协议或空投能力 |
| 返回空投页 | 空投相关条目详情底部 | 跳转到空投准备入口 |

### 11.3 分类

- 觉醒者。
- 量产单位。
- 单位平台。
- 可空投。
- 维修中 / 不可用。

### 11.4 按钮

| 按钮 | 位置 | 功能 |
| --- | --- | --- |
| 角色分类 | 列表区顶部 | 切换觉醒者、量产机、平台 |
| 加入空投候选 | 详情区底部 | 标记该角色用于空投配置 |
| 装备管理 | 详情区底部 | 查看或调整装备 |
| 改装入口 | 详情区底部 | 进入改装相关界面 |
| 查看技能详情 | 技能摘要旁 | 展开技能说明和成长方向 |

## 13. 空投配置界面

### 13.1 目的

让玩家做出本轮远征的正式取舍：坐标、空投舱、觉醒者、量产单位、装备、工具、芯片和资源。

### 13.2 布局

```text
顶部状态栏：坐标 / 空投舱 / 重量 / 格位 / 单位容量
左侧：坐标和空投舱
中央：可选载荷
右侧：当前装载清单
底部：校验错误、警告、取消、确认空投
```

### 13.3 按钮

| 按钮 | 位置 | 功能 |
| --- | --- | --- |
| 选择坐标 | 左侧坐标行 | 设置本轮远征目标 |
| 选择空投舱 | 左侧空投舱行 | 设置本轮空投舱 |
| 添加 | 中央列表行右侧 | 把单位或物资加入装载清单 |
| 减少 / 移除 | 右侧装载清单行右侧 | 减少数量或移出装载 |
| 数量步进器 | 资源类条目旁 | 调整堆叠物资数量 |
| 清空装载 | 底部左侧 | 清除当前选择 |
| 返回轨道站 | 底部左侧 | 放弃本次配置，回空投页 |
| 确认空投 | 底部右侧主按钮 | 校验通过后创建远征并进入地表 |

底部校验区显示超重、超格、单位容量超限、库存不足、前置未满足、禁止携带和警告。

## 14. 地表远征 HUD

### 14.1 目的

服务 RTS 操作、资源采集、基地建设、探索、战斗和火箭返航。

### 14.2 布局

```text
顶部：资源栏、电力、提醒
中央：地图、单位、建筑、资源点
左下：小地图
底部：选择信息面板
右下：命令按钮区
右侧：消息和事件提示
```

### 14.3 顶部资源栏

显示：

- 金属。
- 硅。
- 稀土。
- 能源块。
- 废料。
- 高级资源摘要。
- 电力状态。
- 当前基地状态或警告。

按钮：

- 点击资源图标：打开资源详情或库存摘要。
- 点击电力状态：打开电力详情。
- 点击警告提示：定位到问题建筑或事件。

### 14.4 小地图

显示：

- 已探索区域。
- 未探索区域。
- 当前视野框。
- 资源点。
- 废墟。
- 特殊信号。
- 威胁点。
- 火箭组装坪位置。

按钮：

- 点击位置：镜头移动到对应区域。
- 扫描按钮：打开扫描 / 探索界面。
- 放大按钮：打开全屏地图。

### 14.5 选择信息面板

单单位选中显示：

- 头像、名称、类型。
- 耐久、能源。
- 携带库存。
- 当前指令。
- 行为模式。
- 装备和改装件摘要。

多单位选中显示：

- 单位头像网格。
- 数量。

## 20. 界面流转规则

### 20.1 轨道站内部流转

- 库存、交易、研发、角色、空投通过左侧页签切换。
- 交易和研发成功后停留在当前页，并刷新库存和状态。
- 空投页点击进入空投配置后，离开轨道站主界面。
- 空投配置取消后返回轨道站空投页。

### 20.2 地表内部流转

- 地表 HUD 是默认状态。
- 建造、生产、电力、地图、行为模式、火箭装载都是覆盖面板或子界面。
- 关闭子界面后回到地表 HUD。
- 火箭确认发射后进入回归结算。

### 20.3 失败流转

- 空投配置校验失败：停留在空投配置，显示原因。
- 地表资源不足：停留在地表，提示缺少物资。
- 火箭未建成：停留在地表，提示火箭状态。
- 火箭货舱无效：停留在火箭装载界面，显示原因。
- 结算写入失败：停留在结算界面，显示错误。

## 21. 功能性验收清单

每个 UI 阶段完成时检查：

- 玩家从哪里进入该界面。
- 玩家从该界面去哪里。
- 主功能区、详情区和操作区是否清晰。
- 主要按钮是否有明确位置和功能。
- 禁用按钮是否显示原因。
- 轨道站是否服务准备决策。
- 地表 HUD 是否服务 RTS 操作。
- 空投配置是否表达重量、容量、单位和物资取舍。
- 火箭装载是否表达带回和遗留取舍。
- 回归结算是否复盘带入、带回、损失、遗留和发现。
- 新游戏流程是否进入正式游戏内容，而不是独立图片页。
- 随机事件提示是否保持主动探索节奏。

## 22. 后续风险

需要持续关注：

- 主入口功能外溢，影响继续游戏和新游戏。
- 轨道站入口被做成大图首页，准备效率下降。
- 交易和研发缺少消耗后结果预览。
- 空投配置没有清楚表达取舍。
- 地表 HUD 命令区不清晰。
- 建造、生产、电力面板找不到失败原因。
- 火箭装载缺少遗留预览。
- 回归结算缺少损失、遗留和发现。
- 调试入口混入正式 UI。
